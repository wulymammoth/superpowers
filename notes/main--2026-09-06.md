## Method

Codex CLI 0.153.4, authenticated through the existing ChatGPT subscription.
Each case ran in a separate ephemeral CLI session with workspace-write
sandboxing and `--ignore-user-config --skip-git-repo-check --json`. No model
override was supplied. This records CLI-default behavior, not a model-pinned
comparison. Local AGENTS.md directed each subject to the relevant local skill.
The fixture's `.agents/skills` was copied from the tested source; every skill
file was byte-compared afterward with zero mismatches in all five fixtures.

Raw events, prompts, final responses, and fixtures remain local under
`/private/tmp/superpowers-v630-codex-behavior`. They are not published.
The scope/acceptance cases use synthetic image fixtures and supplied completion
context; they test workflow decisions, not screenshot fidelity or installed
plugin discovery. Outputs were read and filesystem effects checked by the
integration executor. There was no independent model judge.
