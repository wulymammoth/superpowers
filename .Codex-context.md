# Maintained fork context

This fork retains the PNG-based supervised Design Lock contract. Its governing
design is `docs/superpowers/specs/2026-08-07-visual-design-lock-v2-design.md`;
the supervised implementation gates are carried by brainstorming, visual-companion,
writing-plans, and verification-before-completion, with structural regressions in
`tests/design-lock-supervised-contract.test.js`.

When integrating upstream workflow changes, preserve semantics as well as text:

- Visual implementation and Design Lock finalization require the written-spec
  and writing-plans path, including approved PNGs, the visual file allowlist,
  and final human screenshot-and-diff acceptance. Ordinary nonvisual bounded
  tasks may use upstream's no-document path; throwaway exploration may be a spike.
- SDD rulings cannot resolve visual authority conflicts on the human's behalf,
  waive required artifacts, expand the approved allowlist, or replace acceptance.

The v6.3.0 integration exposed both conflicts despite a conflict-free Git merge.
See `notes/main--2026-09-05.md` for evidence and local delivery state. Publishing
and installed-plugin refresh are separate from local integration verification.
